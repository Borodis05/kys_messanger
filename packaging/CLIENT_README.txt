КОРПОРАТИВНЫЙ ЧАТ — КЛИЕНТ

1. Распакуйте архив целиком. Не переносите один EXE отдельно от папки certs.
2. Запустите ChatClient.exe.
3. Введите IP-адрес компьютера-сервера, например 192.168.1.10.
4. Выберите вход или регистрацию.

Клиент запомнит адрес в файле client-settings.json рядом с программой.
Для подключения сертификат сервера должен быть создан именно для этого IP.

Если Windows Defender покажет предупреждение для самостоятельно собранного
приложения, нажмите «Подробнее» и проверьте источник файла перед запуском.
