КОРПОРАТИВНЫЙ ЧАТ — СЕРВЕР

1. Распакуйте архив целиком на компьютере-сервере.
2. Разрешите входящие TCP-подключения к порту 8888 в брандмауэре Windows.
3. Запустите ChatServer.exe. Сервер принимает подключения из локальной сети.
4. Не закрывайте консоль, пока чат должен работать.

База данных автоматически появится в data\chat.db рядом с программой.
Папка certs содержит закрытый ключ сервера. Не передавайте server.key клиентам.
Останавливайте сервер сочетанием Ctrl+C.
