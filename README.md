# Корпоративный чат — этап 3

Консольный TCP-чат поддерживает несколько одновременных клиентов и использует
структурированный JSON-протокол. Каждый пакет передаётся в UTF-8 одной строкой и
завершается символом `\n`.

Требуется Python 3.9 или новее. Сторонние библиотеки не нужны.

## Возможности

- асинхронная работа нескольких клиентов;
- общий чат и уникальные имена пользователей;
- JSON-пакеты с явными типами;
- `request_id` для сопоставления запросов и ответов;
- структурированные подтверждения и ошибки;
- проверка типов, обязательных полей и размеров пакетов;
- системные события о входе и выходе;
- временные метки сообщений в UTC.

## Запуск

Из корневой папки проекта запустите сервер:

```powershell
python -m server.server
```

В отдельных терминалах запустите клиентов:

```powershell
python -m client.client --name ivan
python -m client.client --name anna
```

Команда `/exit` отключает клиента, `Ctrl+C` останавливает сервер.

Для работы в локальной сети:

```powershell
python -m server.server --host 0.0.0.0 --port 8888
python -m client.client --host 192.168.1.10 --port 8888 --name ivan
```

## Примеры протокола

Вход клиента:

```json
{"type":"join","request_id":"join-1","name":"ivan"}
```

Сообщение клиента:

```json
{"type":"chat_message","request_id":"msg-1","text":"Привет!"}
```

Успешный ответ сервера:

```json
{"type":"response","ok":true,"action":"chat_message","request_id":"msg-1"}
```

Сообщение, рассылаемое участникам:

```json
{"type":"message","sender":"ivan","text":"Привет!","sent_at":"2026-11-26T16:00:00+00:00"}
```

Ошибка:

```json
{"type":"error","ok":false,"code":"invalid_message","message":"Некорректное сообщение.","request_id":"msg-1"}
```
