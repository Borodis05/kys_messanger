# Корпоративный чат — этап 1

На первом этапе реализованы настоящий TCP-сервер и консольный клиент. Клиент
отправляет серверу текстовые сообщения, а сервер подтверждает их получение.

Требуется Python 3.9 или новее. Сторонние библиотеки не нужны.

## Запуск

Откройте два терминала в корневой папке проекта.

В первом запустите сервер:

```powershell
python server/server.py
```

Во втором запустите клиент:

```powershell
python client/client.py
```

Введите сообщение и нажмите Enter. Команда `/exit` завершает работу клиента,
а `Ctrl+C` останавливает сервер.

По умолчанию обе программы используют `127.0.0.1:8888`. Адрес и порт можно
переопределить:

```powershell
python server/server.py --host 0.0.0.0 --port 9000
python client/client.py --host 192.168.1.10 --port 9000
```

На этом этапе сервер обрабатывает клиентов по очереди. Одновременная работа
нескольких клиентов будет добавлена на следующем этапе.
