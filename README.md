# Корпоративный чат — этап 2

Консольный чат работает по TCP и поддерживает одновременное подключение
нескольких пользователей. Сервер построен на `asyncio`, принимает сообщения от
клиентов и рассылает их всем участникам общего чата.

Требуется Python 3.9 или новее. Сторонние библиотеки не нужны.

## Возможности

- одновременная работа нескольких клиентов;
- уникальные имена пользователей;
- общий чат с рассылкой сообщений всем участникам;
- системные уведомления о входе и выходе;
- ограничение имени до 32, а сообщения — до 2000 символов;
- корректная обработка отключений.

## Запуск на одном компьютере

Откройте отдельный терминал для сервера:

```powershell
python server/server.py
```

Затем откройте по терминалу для каждого клиента:

```powershell
python client/client.py --name ivan
python client/client.py --name anna
```

Введите сообщение и нажмите Enter. Оно появится у всех подключённых
пользователей. Команда `/exit` завершает работу клиента, а `Ctrl+C` останавливает
сервер.

## Запуск в локальной сети

Сервер должен слушать все сетевые интерфейсы:

```powershell
python server/server.py --host 0.0.0.0 --port 8888
```

Клиенты указывают локальный IP серверного компьютера:

```powershell
python client/client.py --host 192.168.1.10 --port 8888 --name ivan
```

В брандмауэре серверного компьютера должен быть разрешён входящий TCP-порт
`8888`.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Текущий протокол остаётся текстовым: имя и каждое сообщение передаются отдельной
строкой в UTF-8. Структурированный JSON-протокол будет добавлен на следующем
этапе.
